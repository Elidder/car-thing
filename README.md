# Car Thing

Веб-копия **Spotify Car Thing** — плеер-пульт для Spotify, который работает в браузере на любом устройстве: телефоне, планшете, ПК, старом смартфоне в машине.

**Открыть:** https://elidder.github.io/car-thing/

Сайт управляет музыкой, которая играет в вашем Spotify (на телефоне, ПК, колонке и т.д.) через Spotify Web API. Сам он звук не воспроизводит.

## Возможности

### Now Playing
- Фон окрашивается в цвет обложки, как на Car Thing
- Большая обложка, название трека, исполнитель, откуда играет (плейлист / альбом)
- ♥ лайк, ⏮ / ⏯ / ⏭, меню «⋯»
- Полоса прогресса: плавно идёт, по нажатию мгновенно перематывает
- 🔊 громкость: ползунок, кнопки −/+, колесо мыши; повторное нажатие закрывает панель
- Поддержка подкастов

### Библиотека
- Вкладки: Недавнее, Пресеты, Плейлисты, Альбомы, Исполнители, Подкасты
- Карусель обложек (на вертикальном экране — сетка)
- Страница плейлиста / альбома / исполнителя / подкаста со списком треков
- Мини-плеер внизу

### Меню «⋯» и настройки
- Перемешивание, повтор (выкл / всё / один трек)
- Очередь
- Выбор устройства воспроизведения
- Тип аккаунта: Premium / Бесплатный (на бесплатном — только просмотр)
- Часы при бездействии (вкл / выкл)

### Пресеты
4 пресета, как 4 кнопки сверху у настоящего Car Thing. Нажатие — включить, удержание — сохранить то, что сейчас играет.

### Часы в режиме ожидания
Через 10 секунд без касаний экран слегка темнеет и размывается, поверх — крупное время, дата и текущий трек. Касание будит экран.

### Адаптивность
Интерфейс заполняет любой экран: горизонтально — раскладка Car Thing, вертикально — обложка сверху, библиотека сеткой. На больших мониторах масштаб ограничен.

## Управление

| Car Thing | Клавиатура / мышь | Сенсорный экран |
|---|---|---|
| Крутилка | колесо мыши, стрелки | прокрутка |
| Нажатие крутилки | Enter / пробел | тап |
| Кнопка «назад» | Esc / Backspace | кнопка ‹ |
| Пресеты 1–4 | клавиши 1–4 (удержание — сохранить) | вкладка «Пресеты» |
| — | ↑ / ↓ в библиотеке — вкладки | свайп ← / → на Now Playing — трек, ↓ — библиотека, ↑ — очередь |

На экране Now Playing крутилка меняет громкость.

## Требования
- Аккаунт Spotify. Управление воспроизведением требует **Spotify Premium** (ограничение Spotify API).
- Spotify должен быть открыт на каком-нибудь устройстве.

## Установка как приложение
Сайт — PWA: в браузере телефона «Добавить на главный экран», он откроется на весь экран.

## Настройка Spotify (для разработчика)
1. https://developer.spotify.com/dashboard → приложение (Client ID в `index.html`, константа `CID`).
2. В **Redirect URIs** должен быть: `https://elidder.github.io/car-thing/callback`
3. В разделе **User Management** добавить email-ы аккаунтов, которые будут входить (в Development mode вход разрешён только им).

Вход — Authorization Code + PKCE, секрет не нужен. `404.html` перехватывает `/callback` на GitHub Pages и передаёт код обратно в `index.html`.

## Файлы
- `index.html` — всё приложение (HTML + CSS + JS)
- `404.html` — обработка OAuth-редиректа на GitHub Pages
- `sw.js` — service worker (сначала сеть, кэш — офлайн)
- `manifest.json` — PWA-манифест
